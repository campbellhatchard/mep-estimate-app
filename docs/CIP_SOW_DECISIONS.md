Approved decisions from design review:
1. CIP New Client SOW eligibility: CIP + Net New + CIP Install only.
2. CIP deployment: Cloud Inventory hosted only; no deployment selection.
3. Limited Load Test: omit when approved calculation has zero LLT hours.
4. CIP Product Version: controlled as Current Version in Calculation Data; Net New always uses the current version and pins it to the SOW at creation.
5. Appendix ERP/System rules: Deployed Over drives display; Standalone omits ERP details; JD Edwards requires Base Code and Tools Release; other systems use applicable general fields.
6. Barcode Printer Count: SOW-specific field.
