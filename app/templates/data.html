Changing a Calculation Data Element

Controlled changes are versioned and independently approved so historical estimates remain reproducible.
  1. Do not edit the Active version in place. Calculation Data is version controlled.
  2. If a change is required, create a Draft configuration from the current Active {{product_type}} model, or select an existing Draft.
  3. Use Search and Category filters to locate the Calculation Data element you need to change.
  4. Review the element's category, internal key, current value/type, description, scope and active status before changing it.
  5. Change only the controlled value or metadata required. Calculation formulas are source controlled and are not edited on this page.
  6. Enter the mandatory Change Reason describing what changed and why.
  7. Save the change and review dependent estimates/calculations or agreed test scenarios to confirm the expected impact.
  8. Submit the Draft for independent review. A user who created, edited, reopened or submitted the version cannot approve or reject it.
  9. The independent reviewer must record a review reason and either Approve or Reject the version. Rejected versions are locked until explicitly reopened as Draft.
  10. Only an Approved configuration can be activated. Activation retires the prior Active version for this product.
  11. Existing approved estimate revisions remain pinned to their historical configuration and calculation engine. Only new estimates or explicitly rebased revisions use the newly Active configuration.
